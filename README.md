## 🚀 Destaque de Projetos

### **AuraTrade**
Plataforma Full Stack de monitoramento de criptoativos em tempo real. Utiliza um backend robusto em **Java/Spring Boot** para consumir a API da Binance e disparar alertas inteligentes via **Telegram Bot**. O frontend conta com uma interface moderna em React e ticker de preços animado.

### **Signalist**
Plataforma de inteligência financeira que consolida dados de múltiplas fontes para gerar sinais de investimento e análises de mercado precisas. Utiliza arquitetura orientada a eventos para alta performance.
